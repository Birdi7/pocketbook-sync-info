# Политика конфиденциальности

**Приложение:** PocketBook Google Books Sync. **Дата обновления:** 29 октября 2026 года.

## Какие данные использует приложение

Приложение получает от Google идентификаторы, названия и авторов загруженных вами книг, доступные ссылки скачивания и сами EPUB/PDF-файлы. Эти данные нужны для отображения результата синхронизации и загрузки книг на вашу читалку.

Для доступа используется Google OAuth. Разрешение `https://www.googleapis.com/auth/books` позволяет управлять книгами, однако приложение использует его только для чтения списка ваших загрузок и скачивания доступных исходников. Оно не изменяет и не удаляет книги в Google-аккаунте.

Пароль вводится на сайте Google и не передаётся приложению.

## Где хранятся данные

Токены доступа и обновления сохраняются локально на компьютере, на котором выполняется вход, и на читалке после переноса авторизации. Книги, состояние синхронизации и диагностические журналы также хранятся локально. Журналы могут содержать названия и идентификаторы книг и причины ошибок.

Приложение не обеспечивает собственное шифрование этих файлов. Доступ к файлам устройства может дать доступ к сохранённой авторизации.

## Передача данных и сторонние сервисы

Приложение обращается к Google для входа, обновления доступа, получения списка книг и скачивания файлов. У приложения нет сервера разработчика, рекламы, аналитики или продажи пользовательских данных. Книги, журналы и токены не отправляются разработчику автоматически.

На читалке используется DNS-сервис выбранной Wi-Fi-сети. Необязательный диагностический режим на компьютере использует Cloudflare DNS over HTTPS для разрешения имён серверов; DNS-запросы не содержат Google OAuth-токенов или содержимого книг.

Информация, полученная через Google APIs, используется с соблюдением [Google API Services User Data Policy](https://developers.google.com/terms/api-services-user-data-policy), включая требования Limited Use.

Этот информационный сайт размещён на GitHub Pages. При посещении сайта GitHub обрабатывает сетевые запросы в соответствии со своей [политикой конфиденциальности](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). На сайте нет добавленной разработчиком аналитики, форм входа или загрузки книг.

## Управление доступом и удаление

Вы можете отозвать доступ через [подключения Google-аккаунта](https://myaccount.google.com/connections). После отзыва приложение не сможет продолжать работу с Google без нового входа; уже скачанные книги и локальные файлы сохранятся.

Чтобы удалить локальные данные, удалите скачанные книги, журналы, резервные копии и файл авторизации приложения с компьютера и читалки. Удаление локальной копии не удаляет книгу из Google Books.

## Контакт

Вопросы можно задать через [репозиторий информационного сайта](https://github.com/Birdi7/pocketbook-sync-info/issues). Обращения там публичны: не прикладывайте токены, файлы авторизации или приватные журналы.
